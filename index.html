Full stack application · File intelligence

FLUX case study.

A file workspace that brings uploads, processing tools, and downloadable results into one interface.

Project focus

Make a varied collection of file tools accessible through a consistent workflow: choose a tool, upload a file, follow its progress, and retrieve the output.

Implementation

A React/Vite interface connects to an Express API through typed OpenAPI contracts. The repository separates the workspace, API routes, processing engine, and shared types.

What was built

  • Drag-and-drop and file-picker upload interfaces.
  • Processing states for queued, processing, completed, and failed jobs.
  • Download endpoints for completed results.
  • A responsive landing page and workspace, with dashboard activity summaries.

Website design & development · Wellness

ForVera case study.

A wellness product catalogue with an immersive visual identity and a direct route to product enquiries.

Project focus

Help visitors explore a wellness collection, understand product information, and start a conversation with the distributor.

Implementation

The site combines an HTML and Tailwind CSS layout with JavaScript product interactions and Swiper-based browsing. Typography, imagery, and a green palette establish a consistent wellness identity.

What was built

  • Product collection browsing and quick-view product details.
  • A wellness journey section and answers to common questions.
  • Direct WhatsApp enquiries and a contact section.
  • Desktop and mobile layouts, including compact navigation.
